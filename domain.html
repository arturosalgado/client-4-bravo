Quick Test – Login
Log in to get an access token. Required to call the domain verification API. Ensure auth-api-gateway is running (default port 3007). Add ?apiUrl=http://localhost:PORT if using a different port.
If login fails: (1) Run the Vektr seeder: cd packages/database && npm run db:seed. (2) Ensure CORS_ALLOWED_ORIGINS in .env includes null when opening this file from disk.
Choose a verification method to add a Domain to your Organization
Select how you want to verify domain ownership.

Enter a valid email address that ends exactly with the domain you are verifying. We will send a secure link to this address to confirm ownership.

Note: To verify company.com, the email must end in @company.com. To verify sales.company.com, the email must end in @sales.company.com.

You can enter your own email if you plan to verify it, or that of another person if you prefer that they verify it.

Add the unique token below to your DNS records on your domain's nameserver to prove ownership.

- Verify Now: Leave the email field blank. Click Verify after you have added the record.
